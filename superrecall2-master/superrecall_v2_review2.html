🔴 One critical issue survived — in new clothing
Security
Firebase key still ships in every binary. The move to String.fromEnvironment('FIREBASE_WEB_API_KEY', defaultValue: '…') is the right pattern, but the real key is still the defaultValue. Dart's fromEnvironment is resolved at compile time — if the CI/build environment doesn't define those variables, the fallback is baked into the compiled binary exactly as before. Until the CI pipeline actively injects the env vars and the defaultValue fields are left empty (or removed), this provides zero protection in practice.
🟡 New regression introduced
Regression
monthsToGoal lost for brand-new users. StorageService.getProgress() returns null early when lessons.isEmpty && quizzes.isEmpty — i.e. a fresh install. But monthsToGoal is now bundled into the same return value, so a user who sets their goal date before completing any lessons will lose it on the next restart. The fix is to not short-circuit when lessons/quizzes are empty if settings exist, or load monthsToGoal via a separate settings read in ProgressController.init().
🟡 Remaining warnings
SRS
Ease-factor cap of 5.0 is too aggressive. With no upper bound below 5.0, after ~8 consecutive perfect reviews an interval can balloon to years before hitting the 3,650-day cap. Most SRS research (and Anki) caps ease at 2.5–3.0. Consider capping at 3.0 — it still rewards good recall without producing decade-long gaps after a single strong run.
Sync
Merge strategy is asymmetric for monthsToGoal. Lessons and SRS use "local wins"; monthsToGoal uses "remote wins" (with a comment acknowledging the lack of timestamps). A user who updates their goal on their phone, then opens the web version for the first time, will have their setting silently overwritten. Consistent local-wins or a last-write-wins timestamp would be cleaner.
Tests
New logic has no new tests. The _mergeData() function and the monthsToGoal storage path are both logic-heavy and both untested. A merge function with union semantics is exactly the kind of thing that breaks subtly — add at least 3 unit tests covering: local-only data, remote-only data, and a conflict where both have the same lesson id.
